# Глоссарий

Один глоссарий на все системы. Термин добавляется через PR, как любой артефакт.
Формат: термин (оригинал на английском) — определение. В скобках — где используется, если термин специфичен для системы.

| Термин | Оригинал | Определение |
|---|---|---|
| Контракт API | API contract | Формальное описание интерфейса в OpenAPI: пути, параметры, схемы, ошибки. Источник истины — `openapi.yaml` |
| Карточка метода | Method card | Описание поведения одной операции API: логика, маппинг, ошибки, негативные сценарии. Не дублирует схемы контракта |
| Идемпотентность | Idempotency | Свойство операции: повторный вызов с тем же `Idempotency-Key` не меняет результат и не выполняет действие повторно |
| Сквозной идентификатор | Correlation ID | `X-Correlation-Id` — UUID, связывающий все вызовы одной бизнес-операции в логах |
| Ломающее изменение | Breaking change | Изменение контракта, после которого существующий потребитель может перестать работать |
| ПИНФЛ | PINFL | Персональный идентификационный номер физического лица (14 цифр) |
| ИНН | TIN | Идентификационный номер налогоплательщика (9 цифр для юрлиц) |
| <термин> | <original> | <определение> |
